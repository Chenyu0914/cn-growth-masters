# China Growth Masters Skills Pack

中国本土增长大师 Skill 合集，基于唐兴通、申晨、李彦、于玮麟四位专家的方法论蒸馏而成。

## 安装

```bash
# 单独安装
npx skills add Chenyu0914/tang-xingtong-growth
npx skills add Chenyu0914/shen-chen-panda
npx skills add Chenyu0914/li-yan-growth-engineering
npx skills add Chenyu0914/yu-weilin-private-domain

# 或一次性安装全部（需配合 skills.json）
npx skills add Chenyu0914/cn-growth-masters
```

## Skill 清单

| Skill | 专家 | 核心能力 | 适用场景 |
|-------|------|----------|----------|
| `tang-xingtong-growth` | 唐兴通 | 新4C法则、社交裂变、种子用户 | 微信裂变、社群增长、冷启动 |
| `shen-chen-panda` | 申晨 | 熊猫罗盘、内容营销、品效合一 | 内容策划、品牌IP、抖音本地生活 |
| `li-yan-growth-engineering` | 李彦 | 增长工程化、AARRR、数据体系 | 目标拆解、数据驱动、游戏化增长 |
| `yu-weilin-private-domain` | 于玮麟 | 私域水轮、四力模型、公私域联动 | 私域搭建、用户分层、微信运营 |

## 与海外 Skill 的协同

本套 Skill 与 `garyvee-content`、`neil-patel-seo`、`mrbeast-video` 形成互补：

- **GaryVee** 提供创意与叙事 → **申晨** 选择场景与情绪包装
- **Neil Patel** 提供数据与SEO → **李彦** 填充增长决策模型
- **MrBeast** 提供视频Hook与视觉 → **唐兴通** 实现微信私域二次裂变
- **四大师** 共同构建中国本土平台洞察（微信/抖音/小红书/快手）

## 使用示例

```
用户：我要为一个新茶饮品牌设计抖音+微信的增长方案

→ 调用 shen-chen-panda：用熊猫罗盘确定"立场景"（办公室下午茶/露营伴侣）
→ 调用 li-yan-growth-engineering：用五层逻辑倒推GMV目标与所需DAU
→ 调用 tang-xingtong-growth：设计微信社群裂变（拼团/分享赠饮）
→ 调用 yu-weilin-private-domain：搭建私域矩阵沉淀用户资产
```
